# SP-Private-Doc-Collaboration-Template
This repository is where all private "Community Newsletter" files/docs featured on the SP Platform are housed, branched, and collaborated on. This is specifically for business strategy proposals, patent proposals, and other sensitive docs that are not publicly available. All docs in this repo are protected by the SPDX License (included in repo).

## SP Private Doc Collaboration

This is the private repository that **Strategic Pivot (SP)** uses to store your confidential collaboration documents. SP's GitHub App writes to it on your behalf when you create, edit, and accept versions of documents in SP.

### Set it up

1. Click **Use this template** on the template page and choose **Create a new repository**.
2. Name the new repository **`SP-Private-Doc-Collaboration`**.
3. Set the visibility to **Private**. **This is required.** SP refuses to connect a public repository and re-checks before every write.
4. In SP, open **Settings** and connect this repository by installing the **SP Private Collaboration Bot** GitHub App on **only this repository**.

### Rules

- **Keep the repository private**, always. Making it public exposes every document in its history permanently.
- **Do not rename, move, add, or delete folders or files.** SP creates one folder per document and manages every file in it (`version-main.md`, `version-1.N.md`, and so on). Editing them in GitHub directly can break SP's sync and may block edits until an SP administrator repairs it.
- **Do not add collaborators.** People you work with are added as members of your document group inside SP, which controls what each person can see. Adding someone in GitHub gives them access to **every** document in the repository.
- **Do not rewrite history** (no force pushes, no deleting the repository). SP keeps a copy of accepted versions, but your agreement with SP and your group expects the history to remain intact.
- **Do not store anything else here**, such as credentials, other projects, or files unrelated to your SP projects & articles.
- If you disconnect the repository or uninstall the App, SP pauses edits to your documents and tells your group members.
